# 2.1.4-rc1 候选版复核

基线：正式版 2.1.3，提交 `e54fb3c`。本批处理上一轮建议的第 1、2、3 组，等待用户真机回归。

## 改动与影响

1. 设置保存：统一通过有界串行队列执行，取消界面提前更新；异常显示提示且不终止后续保存。磁盘写入失败时回滚本次涉及的内存键；日志不记录设置值或密钥。设置显示可能稍晚于点击，远程同步仍使用已有重试机制。
2. Mock Provider：接入海拔、速度、垂直/速度精度、Android 14+ 海平面高度参数以及随机偏移。同一轮所有 provider 共用一个位置样本，随机点遵守经纬度边界；启用随机偏移后会按预期出现范围内移动。
3. 腾讯坐标：BD-09 输出进入腾讯接口时转换回 GCJ-02，匹配该接口的类型标记。WGS-84/GCJ-02 保持原有路径。仍需实测使用 BD-09 配置的腾讯 SDK 页面。
4. 腾讯监听器：查找表使用弱引用，按 manager 和 listener 身份隔离；连续监听可复用，单次完成及注册失败清理相应记录，取消成功后再删除映射。SDK 持有活动代理期间原 listener 仍正常存活。需要测试重复定位、退出重进、停止后重新启动。
5. 性能：系统服务反射查找缓存命中和未命中结果；无监听/暂停时停止每秒补发轮询，由配置变化和注册唤醒，有限时请求保留到期清理。最需要真机验证的是长时间暂停后重新开始模拟仍能恢复定位。
6. 可维护性：移除未引用的 `LocationIdentityHooks`；无法识别 provider 的旧接口仅记录一次签名，不打印坐标或请求参数，继续沿用 Android 原生处理。

## 明早安装测试

覆盖安装同签名候选 APK 后重启，保持当前作用域与 WGS-84 设置。依次测试：

- 模拟开启，系统定位关闭和开启两种情况下，微信、企业微信、高德、美团各获取一次定位。
- 停止模拟，等待约一分钟，再开启；目标应用退出页面重进后能获取模拟位置。
- 企业微信同一定位页连续进出数次，确认无持续加载或崩溃。
- 修改速度/海拔等参数，退出设置再进入确认保存；如使用 Mock Provider，再检查这些参数及随机偏移。

本候选未包含支付宝专项修复、Wi-Fi 身份值调整或跨 ROM GNSS/NMEA 验证。编译与单元测试不能替代上述真机检查。
